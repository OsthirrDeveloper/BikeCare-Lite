# BikeCare Lite

The Bike Maintenance Tracker is a web app designed to help bikers track and maintain their bike's health with features like reminders for tasks such as chain lube, brake checks, and tire pressure. Pre-added maintenance tasks for the Veloce Legion 10 include regular checks and services like gear tuning and hub greasing. It supports desktop notifications to notify users when tasks are due. The app has a responsive UI built with Radix UI. Users can log, track, and edit maintenance tasks easily and personalize their maintenance schedules.

To get started, take a look at src/app/page.tsx.
