# **App Name**: BikeCare Lite

## Core Features:

- Maintenance Logging: Log bike maintenance tasks (chain lube, brake checks, tire pressure).
- Maintenance Overview: View a summary of maintenance tasks performed and upcoming.
- Maintenance Reminders: Set maintenance reminders for specific tasks.

## Style Guidelines:

- Primary color: A clean, bright white or light gray for the background.
- Secondary color: A calming blue (#3498db) for primary actions and headings.
- Accent: Orange (#e67e22) for highlights and important alerts.
- Clean and modern layout with a focus on easy navigation.
- Use clear, recognizable icons for maintenance tasks.
